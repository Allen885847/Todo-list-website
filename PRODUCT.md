# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The primary user plans schoolwork and personal commitments throughout the day on desktop and smaller screens. They need to see what is due, capture tasks quickly through typing, voice, or files, and move between a focused list and a broader calendar without losing context.

## Product Purpose

The product turns natural-language input into an editable, persistent To-Do List and calendar. Success means users can capture work quickly, understand what is due today or overdue, and trust that tasks, events, holidays, labels, completion state, and preferences will still be present later.

## Positioning

One workflow combines multilingual AI task extraction, voice and document capture, editable review, subject-and-date organization, personal calendar events, and local or account-scoped persistence without turning events into completion tasks.

## Operating Context

Users repeatedly open the product to review today’s work, add or edit tasks, complete items, reorder work, inspect due dates in Day, Week, Month, or Year views, and add personal events. The online version includes account authentication and private cloud data; the desktop version opens directly and uses its independent local save file.

## Capabilities and Constraints

- Preserve existing task, event, holiday, label, completion, appearance, and calendar data formats.
- Preserve text, voice, document, AI, and manual entry flows and their editable review steps.
- To-Do List and Calendar share Light, Dark, and System appearance preferences.
- System appearance follows the user’s device setting.
- English, Mandarin Chinese, and mixed input are supported.
- Online authentication and local desktop storage remain separate systems.
- Existing responsive behavior, keyboard access, page transitions, and reduced-motion support must remain functional.

## Brand Commitments

The product name is Todo List. Interface copy remains concise English. The user has explicitly committed the redesigned interface to a modern blue-based system: soft vivid blue for primary actions, muted purple for events, lavender for Extra, soft red for Overdue, blue-gray for completed tasks, cool white in light mode, deep navy-gray in dark mode, and optional cyan details. Orange and green accents are excluded.

## Evidence on Hand

The repository contains the complete running application, current interface copy, automated behavioral tests, responsive pages, existing SVG icons, and real task/event state rendering. No external marketing claims or photographic assets are required for this application interface.

## Product Principles

- Put the user’s current work before configuration and decoration.
- Make task state, due dates, labels, and event type legible at a glance.
- Keep AI output reviewable and editable before it changes saved data.
- Preserve data and behavior across upgrades, navigation, refreshes, and devices where supported.
- Use motion to explain state changes without slowing down repeated work.

## Accessibility & Inclusion

Maintain keyboard-visible focus, readable contrast in both themes, reduced-motion alternatives, responsive layouts, English UI copy, and multilingual typed and voice input.
